Interpretation and provenance

Each plotted value is an actual logged event. Curves connect observations as a visual guide; no values are interpolated into heatmaps. Missing values remain empty and nonfinite values appear in red.

A heatmap cell shows the final logged event if multiple events share its selected x-coordinate; hovering reports that count. Choose “Chronological event” to expose the complete event order.

With “Real decision” on the x-axis, the same chart slots show episode-wide values. Per-decision summary metrics use this view by default; the heatmap becomes one row of summary values and clicking a column highlights that decision.

Shared-root overlays require the same bank identity, root ID, repeat, solver seed, checkpoint, and probe protocol. Episode overlays compare matching episode IDs and seeds at the selected decision; controllers may already be in different states.
